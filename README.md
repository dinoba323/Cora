# CORA web

Web stranica firme CORA d.o.o. Sarajevo (cora.ba). Next.js, TypeScript, Tailwind CSS.

```bash
npm install
npm run dev
```

Stranica se otvara na http://localhost:3000.

Repozitorij je javan: ovdje ne ide ništa iz administracije firme (ugovori, računi, lozinke, bankovni podaci). Tajne idu u `.env.local`, koji se ne komituje.
